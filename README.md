# Escudo · câmbio Cabo Verde

App web para iPhone que converte escudos cabo-verdianos (CVE) em euros e vice-versa.

- Taxa fixa: 1 € = 110,265 CVE (paridade com o euro). Não há câmbio para atualizar.
- Teclado próprio, botões com as notas (200$ a 5.000$ / 5 € a 100 €) e tabela rápida.
- Mostra quanto perde ao pagar em euros numa loja que conta 1 € = 100$.
- Com `sw.js`, fica guardada no iPhone e funciona sem internet quando servida por HTTPS.

## Instalar no iPhone

1. Abrir https://rbessa66.github.io/escudo/ no Safari.
2. Partilhar → **Adicionar ao ecrã principal**.
3. Abrir uma vez com internet para ficar guardada. A partir daí funciona offline.
